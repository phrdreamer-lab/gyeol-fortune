# 결 — 사주 운세와 이름 살펴보기

[k-skill](https://github.com/NomaDamas/k-skill)의 `saju-fortune`, `naming-house` 스킬을 설치하고 해당 npm 패키지의 계산 결과를 브라우저에서 보여주는 정적 웹 서비스입니다. 원 프로젝트와 제휴하거나 공식 운영하는 서비스가 아닙니다.

## 실행

Node.js 20.19+ 또는 22.12+ 환경에서:

```bash
npm ci
npm run dev
npm test
npm run build
```

`docs/`에 생성되는 정적 파일을 GitHub Pages의 `main /docs`로 배포합니다. 공개 저장소에는 서비스 소스와 빌드 결과가 포함됩니다.
브라우저 통합 테스트는 기본적으로 Windows의 Chrome을 사용하며 다른 경로는 `BROWSER_PATH` 환경변수로 지정할 수 있습니다.

## 안내

- 서버 없이 계산하며 생년월일과 이름을 저장하거나 전송하지 않습니다. 웹폰트는 Google Fonts에서 불러옵니다.
- 양력만 입력받습니다. 음력은 외부의 검증된 만세력으로 먼저 양력 변환해야 합니다. 출생시간을 모르면 시주는 생략됩니다.
- 사주 패키지는 절기 시작일을 고정 날짜로 근사하며 출생지 경도 보정은 적용하지 않습니다. 전문 만세력과 결과가 다를 수 있습니다.
- 작명은 사용자가 입력한 후보만 비교합니다. 한자 미입력 시 한글 획수를 활용합니다. 한자 필순 횟수는 강희자전 원획수나 81수리와 다릅니다.
- 결과는 재미와 자기 성찰을 위한 참고용이며 의료, 투자, 법률, 인명용 한자 검증을 대신하지 않습니다.
